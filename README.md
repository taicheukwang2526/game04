# 🎼 共鳴編年史：魔導樂章 3D (Chronicles of Resonance: Arcane Symphony 3D)

結合 **Three.js 3D 奇幻探索**、**Web Audio API 即時音色合成**、**真實樂器麥克風收音** 與 **樂理聽音戰鬥** 的瀏覽器 ARPG。

## 📂 專案結構
- `index.html`：主程式入口（GitHub Pages 部署版本）
- `legacy/`：原始單檔版本備份
- `css/arcane-hud.css`：暗黑奇幻玻璃擬態 HUD 樣式模組
- `js/audio/sound-engine.js`：Web Audio 合成器與麥克風音高偵測
- `js/data/game-catalog.js`：章節、魔物、裝備套裝與天賦數據庫
- `js/world/three-scene.js`：Three.js 3D 場景、角色與光影系統
- `js/combat/battle-system.js`：聽音對決、五線譜視譜鏡與完美格擋
- `js/minigame/rhythm-gather.js`：節奏採集 3.0 音遊與半音階調音器
- `js/ui/hud-modals.js`：裝備背包、鍛造爐、無盡深淵與作曲工坊 UI
